# Defect Log

Real defects found during development (not hypothetical), all fixed
before the affected feature was considered done. Kept as a historical
record and to justify the regression tests in `tests/`.

| ID | Found during | Description | Severity | Root cause | Fix | Regression test |
|---|---|---|---|---|---|---|
| DEF-1 | M6 real testing | Voice-stage ffmpeg filtergraph mislabelled input indices when generating inter-segment silence, causing "Invalid file index" errors on any script with 2+ segments | High (voice stage unusable with silence gaps) | Two separate counters (`input_idx`, silence-label index) were conflated into one, so silence-source labels collided with real input indices | Track actual `-i` input index separately from the silence-label suffix | Exercised by every e2e test (multi-segment scripts); later simplified further to reuse the loop's own `enumerate()` index (see DEF-5) |
| DEF-2 | Real GPU verification | Subprocess calls using relative venv paths (`envs/face/Scripts/python.exe`) silently failed with `FileNotFoundError: [WinError 2]` on Windows, even though the file existed relative to cwd | High (blocked all real face-stage subprocess calls) | Windows `CreateProcess`'s `lpApplicationName` does not resolve relative to cwd the way a shell does | `echoface/util/proc.py::resolve_exe` resolves to absolute path before every subprocess call that uses a venv-relative default | `tests/unit/test_proc.py` |
| DEF-3 | Real GPU verification, re-running `make` with a fixed `--job-id` | `Job.create()` always wrote a fresh, blank `job.json`, silently discarding all prior stage progress — a repeat `make` invocation with the same `--job-id` unexpectedly redid a ~2 minute GPU face render | High (defeats the whole idempotency/skip mechanism for the `--job-id` reuse path) | `Job.create` never checked whether `job.json` already existed at the target path | `Job.create` now loads-and-returns the existing job if `job.json` already exists at `root/job_id/job.json` | `tests/unit/test_job.py::test_create_with_existing_job_id_preserves_stage_state` |

| DEF-5 | Code review pass (ruff `SIM113`) | `concat_with_pauses` carried a redundant manual counter (`input_idx`) that exactly mirrored the loop's own `enumerate()` index | Low (code smell, not a functional bug) | Leftover from the DEF-1 fix, never simplified afterward | Removed the redundant counter, reused `i` from `enumerate()` | Existing e2e tests still pass unchanged (behaviour-preserving simplification) |

| DEF-7 | Two-pass loudnorm real-audio verification | After DEF-6's fix, one real render's *final AAC-encoded* file measured -0.42 dBTP — over the -1 dBTP requirement — even though the pre-encode PCM correctly measured -1.5 dBTP | Medium (fails NFR loudness spec, encoder-dependent) | AAC re-encoding measurably overshoots the pre-encode PCM's true peak (a known lossy-codec effect) | `compose.true_peak_dbtp` default changed from -1.5 to -2.5 dBTP as the pre-encode target, leaving margin | Manual real-render measurement on two different renders (both landed within spec after the fix) |
